# Database-Work

## Year 1: SQL Database Assignment

This assignment focused on the creation of an SQL database hosted on a web server for a room booking system.

The files for this assignment include:
- coursework.sql (the main file containing the setup for the database)
- delete.sql (an SQL script to delete the database for testing purposes)
- Invalid_Sample_Data.sql (an SQL script to attempt to populate the database with invalid data for testing purposes)
- Valid_Sample_Data.sql (an SQL script to populate the database with valid date)
- RoomBooking.php (the php file containing all the web page information)
- Coursework1 report.docx (the report for the assignment)
